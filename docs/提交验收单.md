# 提交验收单

## 代码与配置

- [ ] `config.local.json` 已填写，未提交 App Secret、token 或验证码。
- [ ] `PERSONA.md` 已换成使用者自己的身份与语料。
- [ ] `BIBLE.md` 已明确直接执行、先确认和禁止动作。
- [ ] 已确认使用白名单，或明确启用了 `allowAllChats`。
- [ ] `knowledge-catalog.json` 只包含已授权文档。

## 飞书链路

- [ ] 用户消息轮询收到群内 @ 真人账号和别人发来的单聊。
- [ ] 应用事件长连接作为辅助通道保持运行。
- [ ] `lark-cli auth check` 返回 `ok: true` 和 `identity: user`。
- [ ] 真实文本已从授权用户身份送达。
- [ ] 图片读取、Word 生成和文件回传均分别验证。
- [ ] 待办/日程只在“确认”后创建。
- [ ] 暂停接管、恢复接管有效。

## 个人微信生产链路

- [ ] 使用固定 Cloudflare Named Tunnel；生产未依赖 `trycloudflare.com` Quick Tunnel。
- [ ] Tunnel Token 只存在 macOS Keychain，Git、配置、进程参数和日志均无凭据。
- [ ] 本地 callback canary 与固定 HTTPS 主机名的公开 canary 均成功。
- [ ] cloudflared metrics 显示四条活跃 edge 连接。
- [ ] GeWe 账号在线，callback 注册地址与固定主机名一致。
- [ ] 真实单聊完成 `received → durable enqueue → replied`，审计证据不含消息正文和联系人标识。
- [ ] 终止 cloudflared 后自动恢复 Tunnel、公开 canary 与 callback 注册。
- [ ] 重启主服务后未重复回复已完成消息，已持久化未完成消息可以继续。
- [ ] 隔离坏 release 已触发 automatic rollback，`current` 恢复到已知良好 commit。

## 钉钉生产链路

- [ ] DWS event-stream 使用本人身份完成认证并显示 ready。
- [ ] 真实单聊入站已持久化并成功回复；另一次主动出站已收到平台成功回执。
- [ ] 重启主服务后 event-stream 自动重连，已完成消息没有重复回复。
- [ ] 微信切换后钉钉链路仍通过，两个渠道共享的持久化收件箱没有异常积压。

## 运行与安全

- [ ] LaunchAgent 状态为 running。
- [ ] 四个生产 LaunchAgent 只指向 `Application Support/AIPRO/current`，不指向仓库或 `.worktrees`。
- [ ] `current` release manifest 的 Git SHA 与上线 commit 一致，release 目录只读。
- [ ] 配置、SQLite 和日志均在 release 目录外；主服务持有 `caffeinate` 睡眠断言。
- [ ] `bridge-error.log` 无持续错误。
- [ ] 数字分身标识符合 `digitalTwinLabel` 配置；空字符串表示不添加。
- [ ] 审计数据库正常写入。
- [ ] 同一消息在轮询与 WebSocket 重复出现时只回复一次。
- [ ] 服务重启后不会回放历史消息，未完成消息可以恢复重试。
- [ ] 压缩包不含 `config.local.json`、`data/`、`*.log`、`node_modules/`。
