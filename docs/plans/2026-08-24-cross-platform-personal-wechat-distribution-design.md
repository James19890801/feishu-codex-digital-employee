# AIPRO 跨平台个人微信数字人发行设计

## 目标

把现有 AIPRO 项目交付为一个可直接转发给非技术用户的总 ZIP。总包同时包含 Windows x64、macOS Apple Silicon 和 macOS Intel 安装器。用户不需要源码、Node.js、Python、Cloudflared 或终端操作；安装后在本地控制台完成运行时选择、GeWe 配置、个人微信扫码、数字人身份设置和真实消息验收。

首版成功标准：全新兼容电脑解压总包并安装对应版本后，能够在图形界面中选择一个通过真实冒烟的 AI 运行时，填写用户自己的 GeWe 服务地址和 Token，扫码连接个人微信，向测试联系人收发一条消息，并在重启电脑后自动恢复运行。

## 交付形态

最终产物只有一个对外总包：

```text
AIPRO-个人微信数字人-<version>.zip
├── Windows/AIPRO-Setup-x64.exe
├── macOS/AIPRO-Apple-Silicon.dmg
├── macOS/AIPRO-Intel.dmg
├── 开始使用.html
├── release-manifest.json
└── SHA256SUMS.txt
```

`开始使用.html` 使用普通浏览器即可打开，按操作系统展示安装、系统首次放行、运行时选择、GeWe 购买与配置、扫码、测试和恢复步骤。总包和每个安装器都有 SHA-256、版本、架构和文件清单。

## 架构

跨平台版本复用现有 Node.js 核心、Dashboard、SQLite 状态、消息策略、记忆和审计，只新增发行层、系统服务层、首次配置向导和运行时适配边界。

```text
个人微信
  ↕
用户自己的 GeWe REST / Webhook 服务
  ↕
Cloudflare HTTPS 回调隧道
  ↕
本机 AIPRO 消息核心
  ├─ 运行时适配层 → WorkBuddy / Codex / Qoder / CodeBuddy / 自定义 CLI
  ├─ 本地 Dashboard
  └─ SQLite / Persona / Bible / 知识 / 日志 / 备份
```

程序资源不可变，用户状态可变且独立：

- macOS 程序位于 `/Applications/AIPRO.app`，用户状态位于 `~/Library/Application Support/AIPRO`。
- Windows 程序位于 `%LOCALAPPDATA%\Programs\AIPRO`，用户状态位于 `%LOCALAPPDATA%\AIPRO`。
- 升级替换程序资源，只补缺失默认文件，不覆盖配置、Persona、Bible、知识、SQLite、日志或备份。

macOS 使用现有 Swift/WKWebView 外壳和用户级 LaunchAgent。Windows 使用轻量 WebView2 启动器、用户级安装器和登录后启动任务。两端都内置对应架构的 Node.js、Python、Cloudflared 和生产依赖；用户不需要安装开发工具。

## 首次配置体验

首次启动进入六步向导：

1. 系统自检：程序完整性、数据目录、端口、后台服务和网络。
2. 选择运行时：展示已检测、可调用、需要登录和不可用原因；必须完成一次真实无界面调用才能继续。
3. 连接 GeWe：填写 API 地址与 Token，验证服务后获取或填写 App ID。
4. 建立回调：默认启动内置 Cloudflared Quick Tunnel，取得 HTTPS 地址，自动注册 GeWe 回调并验证挑战或测试事件。
5. 扫码登录微信：展示二维码、登录状态、微信身份和掉线恢复提示。
6. 设置数字人：填写对外名称、身份说明、回复范围和安全默认值，最后向测试联系人完成一次真实收发。

高级能力默认关闭，包括主动私聊、自动发朋友圈、自动评论、自动欢迎新人和群内无触发回复。默认只允许白名单测试联系人；群聊仅在明确提及数字人时回复；安装者确认后才能扩大范围。

## 个人微信链路

个人微信只使用 GeWe，不恢复已退役的 macOS 桌面 UI 自动化。用户自行购买和管理 GeWe 服务，发行包不内置共享 Token、App ID、微信账号或回调地址。

出站消息通过 GeWe REST API；入站消息通过本机回调端口和 Cloudflare HTTPS 隧道。Quick Tunnel 地址变化时，监督进程原子更新本地配置、重新注册回调并重启微信通道。用户也可以改用自己的固定 HTTPS 域名。

Token 写入 macOS Keychain 或 Windows Credential Manager。普通配置只保存密钥引用。所有日志对 Token、二维码内容、微信 ID、手机号和回调签名做脱敏。

第三方个人微信协议存在封号、掉线、API 变更和服务商故障风险。向导必须明确告知，不承诺官方支持或完全离线，并提供一键暂停、发送频控、每日上限、重复回复保护和人工接管。

## 运行时适配

运行时适配器统一实现探测、版本、认证状态、无界面调用、流式输出、超时、取消和健康检查。当前保留 Codex、Qoder 和 CodeBuddy 适配，并新增可配置的 WorkBuddy/自定义 CLI 入口。

“发现桌面应用”不等于“可用于后台数字人”。只有真实执行最小提示并返回有效文本后，控制台才允许启用。若 WorkBuddy 当前版本没有稳定公开的无界面接口，则显示为“已安装但尚不可用”，用户可选择其内置且可验证的 CLI 或其他运行时；系统不得通过未文档化的进程注入冒充支持。

运行时切换先测试新运行时，再原子保存配置和重启核心服务；失败时保留原运行时。

## 安全与隐私

发行构建继续使用显式白名单和两次隐私扫描，并新增以下禁止项：

- `config.local.json`、Persona、Bible、知识、SQLite、日志、备份和缓存；
- 开发者或测试者的微信 ID、App ID、Token、手机号、群名和回调地址；
- 当前仓库的未跟踪输出、测试夹具和内部文档；
- 私钥、API Key、绝对用户目录和本机运行时路径。

通用默认配置不得包含任何真实人的微信 ID。安装器在复制资源前验证 manifest 和 checksum。后台服务只监听 `127.0.0.1`，Dashboard 使用随机本地管理令牌和严格 Origin 校验。回调端点只开放必要路径，并沿用签名、去重、限流和负载边界。

## 错误处理与恢复

控制台按阶段展示错误，不显示空白页或只给日志路径：

- 安装资源损坏：阻止安装并显示失败文件。
- 端口占用：自动选择允许范围内的新端口并同步服务配置。
- 未发现运行时：保持微信自动回复关闭，给出安装和重新扫描入口。
- 运行时未登录或冒烟失败：保留原配置，不启动消息消费。
- GeWe 凭据无效：不保存 Token 引用，允许重新输入。
- Cloudflare 隧道失败：指数退避重连；期间暂停自动回复，不丢弃已持久化的合格事件。
- 微信掉线：停止外发，展示重新扫码；不得无限重试登录。
- 回调重复：按稳定消息 ID 幂等入队。
- 服务崩溃：系统用户级服务自动重启，单实例锁阻止重复消费。
- 升级失败：恢复上一程序版本和原用户状态。

Dashboard 提供“暂停数字人”“重新扫码”“重建回调”“切换运行时”“导出脱敏诊断包”和“卸载但保留数据”。

## 构建与验收

构建在干净暂存目录中完成。Windows 生成 x64 安装器；macOS 分别生成 arm64 和 x64 DMG；最后生成包含三者的总 ZIP。构建脚本验证二进制架构、签名、必要资源、禁止文件、安装器哈希和总包哈希。

自动测试覆盖：

- 资源目录与用户状态目录分离；
- 三平台目标的打包契约；
- Windows 服务安装、升级、卸载和回滚脚本；
- macOS LaunchAgent 和应用包启动；
- Runtime 探测、真实冒烟、切换回滚；
- GeWe 凭据密钥库、扫码状态、回调注册、隧道 URL 更新；
- 默认安全策略、重复消息、频控、人工暂停；
- 隐私扫描和总包文件清单；
- 临时用户目录中的全新安装与保留数据升级。

最终人工验收至少覆盖一台 Windows 11 x64、一台 Apple Silicon Mac；Intel DMG 通过架构和安装冒烟验证。没有真实 GeWe Token 时，构建可以完成，但对外发布前必须由发布者在隔离测试微信上完成扫码、入站、模型调用、出站、重启恢复和掉线暂停的真实链路验收。

## 非目标

首版不支持 Windows ARM、Linux、完全离线微信、内置或共享 GeWe 账号、自动购买第三方服务、绕过微信风控、自动安装任意 AI 桌面软件，也不承诺任何未经真实无界面冒烟的运行时可用。
