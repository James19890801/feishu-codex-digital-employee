# 詹老师文章自动分发设计

## 目标

当微信号 `fung5115` 或公众号 ID `gh_07e3d1422f5e`、`BPM321GO`、`gh_63f557f95450`、`HuaYu_Consulting_21` 发布文章后，数字人第一时间阅读全文，形成两段不重复的观点：一段用于公众号文章留言，一段用于朋友圈转发语；两项动作分别持久化、重试和去重。

## 方案选择

采用精确来源、事件驱动方案。只处理命中指定微信号或公众号 ID 的微信公众号文章，不让模型猜测作者，不轮询全网，也不把其他人转发的相似标题误判为詹老师文章。

## 数据流

1. GeWe 回调收到 APPMSG/LINK 消息。
2. 标准化层保留文章 URL、标题、摘要、封面、公众号 ID 与公众号名称。
3. 来源策略同时验证发送者和文章内嵌 `sourceusername`；公众号直接推送命中，`fung5115` 转发时必须验证文章公众号 ID。
4. 将微信文章 URL 规范化为 `biz + mid + idx + sn`，生成稳定文章指纹。
5. 公开网页读取器获取正文。正文读取失败时不猜测内容，进入延迟重试。
6. AI 一次生成严格 JSON：文章留言与朋友圈见解。二者都必须有明确判断、基于正文、不得泄露本地或私人资料，也不得长段照抄。
7. 文章留言通过微信客户端适配器提交；朋友圈链接通过 GeWe `sendUrlSns` 发布。
8. 两项动作使用不同的 mutation key。任何回调重放、进程重启或发送结果不确定都不会导致重复发布。

## 内容规则

- 文章留言：40–100 字，针对文章核心观点，像认真读完后的真实补充，不写“学习了”“受益匪浅”等空话。
- 朋友圈见解：70–160 字，给出一个独立判断或反常识观察；不复述留言，不伪装成詹老师本人原话。
- 两段文字不得出现客户、项目、群名、内部账号、联系方式、文件路径或本地知识来源。
- 同一文章永久只留言一次、只转发一次。

## 状态与失败处理

每篇文章保存 `detected/read/generated/commented/shared` 五阶段状态、尝试次数和下次重试时间。文章留言未开放、客户端未登录或控件不可访问时，记录明确原因并保持待处理；朋友圈转发可独立完成。结果不确定时标记 `uncertain`，先核对而不是再次发送。

## 风险边界

GeWe 提供链接朋友圈发布接口，但不提供普通读者给公众号文章留言的接口。公众号文章留言必须借助微信客户端，且属于代表用户对外发表评论。实现保留动作前确认闸门，不通过技术手段绕过微信客户端、验证码或平台安全限制。

## 验收标准

- 精确识别 `fung5115` 与四个指定公众号 ID 的文章，拒绝其他来源。
- 同一文章的不同分享参数归一为同一指纹。
- 正文读取失败不生成、不发送。
- 留言和朋友圈文案有实质观点且互不重复。
- 回调重复十次仍只产生一次留言 mutation 和一次朋友圈 mutation。
