# AIPR0S 每日听记强校验与恢复设计

## 目标

每天 18:00 的知识同步必须通过 `config.local.json` 指定的独立 DWS Channel 读到当天可访问的 AI 听记，并将纪要更新到本地知识库和钉钉 Wiki。短暂失败或异常空列表不得被当成“当天没有会议”并结束。

## 设计

- 听记列表改用当前 CLI 的原子命令 `minutes list all`，以 Asia/Shanghai 当天时间窗口查询“我可访问的全部听记”。
- 每页最多 30 条，继续跟随 `hasMore` / `nextToken` 直到完成；超出安全页数上限时标记未读取，不接受部分成功。
- 列表命令失败、返回异常空列表、或任一条听记详情未取得有效纪要时，在同一独立 Channel 内重试；重试命令增加 `--timeout 60 --verbose`。
- 脚本重试耗尽后返回 `status=unread` 和具体原因，保留听记游标，其他来源仍继续同步。
- 定时任务将听记设为当天强校验来源：`unread` 或计数为 0 时必须执行直接 DWS 诊断并重跑同步，不得报告成功。

## 验收

- 真实 `itemList[].uuid/shareUrl` 数据能生成听记知识记录。
- 首次空列表或瞬时错误会重试，后续成功时正常交付。
- 连续失败或持续空列表会明确标记“未读取”，且失败不推进游标。
- 本地 `state.json` / `index.json` / 当日日报与钉钉 Wiki 节点可回读到当天听记。
